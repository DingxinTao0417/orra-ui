# @orra-ui/styles

Framework-neutral design tokens for Orra UI: semantic colors (light + dark), the composite type scale, shadows, radii and component keyframes, written as Tailwind CSS v4 `@theme` blocks.

```css
@import "tailwindcss";
@import "@orra-ui/styles";
```

React users import `@orra-ui/react/styles.css`, which includes this package. Files: `tokens.css` (colours, shadows, radii), `typography.css` (type scale), `motion.css` (animations, utilities), `base.css` (element defaults).
